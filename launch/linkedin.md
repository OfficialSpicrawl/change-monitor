```
Pricing pages, docs and competitor sites change without telling anyone. Checking by hand does not last two weeks.

change-monitor is a small open-source Node CLI for this. List URLs in a text file; each run fetches every page as Markdown through the Spicrawl API, compares it with the last snapshot and prints what changed. It can post to Discord or Slack. Run it from cron or GitHub Actions.

A block page (403, 503) is reported as blocked, not as a change.

1 credit per URL per check; the free plan has 1,000 a month, failed requests cost 0. The diff is line-based, capped at 20 lines.

Repo, live demo and demo video are in the first comment.
```
